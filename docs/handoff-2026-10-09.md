## 4. 这一轮做完的（2026-10-08 ~ 09）

### 4.1 图标全站重做
`src/ui/icons.js` —— **48 个手绘黑描边 SVG**，全站 emoji 换掉（99 处引用 / 26 种）。
不用 emoji 的真正理由：它彩色、在玻璃+柠檬绿配色里各说各话，而且三个操作系统上长得**完全不同**。
`icon(name)` 同时认图标名和旧 emoji（localStorage 里的老数据不该变成问号）。

### 4.2 来源扇区
左下角一颗按钮 → 90° 扇区弹出 9 个来源，**融合在最核心那格**（45° + 内圈）。
最左栏会被选中的来源染色，融合 = 杂色渐变。

### 4.3 货架
右下角一颗圆球（和左下角来源按钮同一个模式）。**什么都能放**：拖 / ⌘V 粘贴 /
拖图片文件（带缩略图）/ 拖链接 —— 全部走 `shelfAdd` 一个入口。
引导指针每 10 秒跳一秒（**用过一次就不再打扰**）。

### 4.4 结构流（学 Tuna 的 subject → action → target）
- **端口有类型**（`event/text/notes/web/flag/action`），线只能接兼容的两端 ——
  这是"连线有什么意义"的答案。限制只加在**类型**上，不加在内容上。
- 三种版式：卡片（**自由画布，x/y 就是位置**）/ Nuggets / 3D（有厚度）。
- Figma 那种**点阵按缩放重画**（改 `background-size/position`），不跟着 transform 缩。
- 三种线：数据流（实线）/ 顺序（虚线）/ 条件（点线）。
- 执行器：拓扑排序逐块跑，真有执行器（检索 / 调模型 / 放货架 / 念出来 / 弹通知…）。

### 4.5 写回 Notion = 复核台
```
切条 → 一次调用批量分类 → 你勾哪些、每条自己选页面 → 才写
```
- 按钮上带实时计数（「写入 6 条」）。
- **判不出来的不替你决定**：留「? 选一个」+ 标题下明说有几条没判出来。
- **故意没有"以后别问"的勾** —— 读者 2026-10-09 明确要求每次都要自己选。

### 4.6 本地语音识别
```
🎙 按下 → MediaRecorder → OfflineAudioContext 重采样 16k 单声道
       → 浏览器里编 WAV → POST /api/stt → 本机 whisper → 出字 → 送进提问
```
- 环境 `~/.c4emem/stt/venv`（mlx-whisper，M5 的 Metal），模型 `mlx-community/whisper-small-mlx`。
- **音频不出本机。**
- 设置页有「本地语音识别」一段（模型 / 语言可换）。

### 4.7 结构流存到「你自己选的文件夹」（2026-10-09）
```
画布 → 服务端 → <你选的文件夹>/flow.json   （原子写：先 .tmp 再 rename）
```
- **目录可配**：设置页「结构流（画布存哪）」填一个路径（支持 `~`），留空用 `~/.c4emem/flows`。
  旁边那颗「选择文件夹…」走 macOS 原生对话框（`osascript choose folder`）。
  ⚠️ 按钮**只把路径填进框，不直接改设置** —— 还得点「保存」。选和用分成两步，误点不会搬走存储位置。
- ⭐⭐⭐ **画布以「文件夹里那份」为准**，localStorage 降级成首屏缓存：
  · 文件在 ⇒ 以它为准（**这是刻意选的**：你要的是"指到 iCloud/Dropbox 就自动同步"，
    若让本地那份赢，"在 A 机清空"会被 B 机的旧缓存**复活**）；
  · 文件不在而本地有 ⇒ **自动搬上去**（迁移，不然老用户升级就"画布没了"）；
  · ⚠️⚠️ **文件坏了 ⇒ 一个字都不许动**，而且**不开自动存**（`flowReady=false`）。
    这是最贵的一条：静默拿空画布盖掉 = 把用户的画布删了。
    **负向对照已做**（把闸门打开 ⇒ 断言变红），它跑的是「编辑之后文件有没有变」，
    不是"加载完读一眼"—— 后者是**恒等操作**，不编辑就没人推盘，怎么改都绿。
- ⚠️⚠️ **服务端来的块可能没有 x/y** ⇒ 必须补落点，否则全叠在一点、互相挡住、**点都点不到**
  （看起来只是"排得有点怪"）。`ensureSpots()` 在**加载时和 hydrate 之后都要跑**。
- ⚠️ **改了画布存储 ⇒ 四个套件的种法要跟着改**：套件原来往 `localStorage` 种画布，
  会被 hydrate 盖掉 ⇒ **崩**在 `.blk[data-id="b1"]` 找不到上（"套件过期"伪装成"产品坏了"）。
  现在统一走 `scripts/_flowseed.mjs`，**种到服务端 + 临时目录**（绝不碰读者真画布，退出时还设置）。

## 8. 验证

**六个套件，跑法都一样：**

```bash
env -u HTTPS_PROXY -u https_proxy -u ALL_PROXY -u all_proxy -u HTTP_PROXY -u http_proxy \
    NO_PROXY='*' bun scripts/verify-XXX.mjs
```

| 套件 | 管什么 |
|---|---|
| `verify-icons` | 图标是**描边不是填充**、无断引用、文字里无 emoji、知识库聚合、Notion 角标 |
| `verify-flow` | 点阵画布、缩放、三种版式、来源过滤、KB 落空弹窗 |
| `verify-flow2` | **端口类型真的在拦**（正反两面都测）、自由拖拽、连线、发光、3D 厚度（像素负向对照） |
| `verify-ui` | 来源扇区几何、两栏收起、货架不压东西、玻璃浮层 |
| `verify-shelf` | 货架图标 / 指针 / 粘贴（含**输入框里不抢**的负向对照）/ 图片 / 帮助弹窗 / 写回复核台 |
| `verify-stt` | ⭐ **假麦克风端到端**：真录、真重采样、真编码、真识别、真送进提问 |
| `verify-flowstore` | ⭐ **画布存到文件夹**：从文件夹加载 / 迁移 / 编辑落盘 / **坏文件绝不被覆盖**（负向对照）/ 没坐标的块不许叠在一起 |

⭐ **`verify-stt` 的夹具**：`/tmp/stt-test.wav`（**`/tmp` 会被系统清掉**）。
重建命令已经固化在仓库里 —— `bash scripts/mk-stt-fixture.sh [输出路径]`，
套件缺夹具时会**自己调它重建**，所以正常情况下不用管。

```bash
bash scripts/mk-stt-fixture.sh          # 默认写 /tmp/stt-test.wav
```
⚠️⚠️ **文件名只有一处权威：`verify-stt.mjs` 里的 `WAV` 常量。**
曾经出现过两个名字分家（套件读 `stt-test.wav`，而口头文档让人重建 `stt-fixture.wav`）
⇒ **照文档重建出来的文件套件根本不读，症状是「重建了还是跳过」。**

⚠️⚠️ **`verify-stt` 的「跳过」以前是 `process.exit(0)`** —— 退出码和真通过**一模一样**，
任何包装脚本都会当成验过了；而且它在打印汇总行**之前**就退了，
连「跳过了几条」都看不到。现在：**缺夹具先自动重建；重建失败才跳过，
退出码 `2`、汇总行单列、并且明说「这次什么都没验证」。**
判据：**跳过必须是 exit 2，通过必须是 exit 0。**
（同族纪律：FACT 纪律 8「跳过和通过必须长得不一样」。）

**验证纪律（这个项目吃过亏）：**
- ⚠️ **一轮最多跑 2 个套件**，跑 5 个会被 SIGKILL（exit 137）。
- ⚠️ **等条件，不要等固定秒数** ——「没等够」和「功能坏了」在输出里长得一模一样。
- ⚠️ **别写时间相关的断言** —— 引导指针每 10 秒跳一秒，任何瞬时读数都在跟定时器抢时机。
  要么显式清掉状态再读（测样式表默认值），要么等它自己回到稳态。
- ⚠️ **`display:none` 的元素矩形是 0×0** —— 几何要在看得见的时候量。
- ⚠️ **负向对照只动被测的那一侧**，否则写成恒等操作，全绿但什么也没测。

## 9. 这个项目特有的坑

1. ⚠️⚠️ **`spaces` 是库里的键不是界面标签** —— 写错不报错，只是搜不到。
2. ⚠️⚠️ **`minScore: 0.4` 太松** —— 乱码问题也能捞到 0.43~0.49 的噪声，所以另有
   `weakBelow: 0.55`（语义是「这条不太可信」**不是**「没有」，界面上给的是"要不要上网再查"）。
3. ⚠️⚠️ **嵌入服务挂了会 500** —— 已经改成降级成关键词腿并在返回里带 `degraded`。
   但**根因是 ollama 没跑**，遇到 500 先查它。
4. ⚠️⚠️ **`/api/ask` 里的 `source` 字段是「模式」**（voice/text/flow），**不是来源**。
   来源过滤是另一个字段 `spaces`。命名撞车过，别复用。
5. ⚠️ **`notion-append.py` 默认是预览**，加 `--write` 才真写。接口那边是 `dryRun: false`。
6. ⚠️ **改 `src/ui/app.css` 前先 grep 那个选择器有几条规则** —— 同特异型看顺序，
   这个坑犯过六次（见 FACT 纪律 12）。**覆盖旧规则时，不想继承的属性要全部显式重置。**
7. ⚠️ **`src/ui/app.js` 里同一个 `const` 不能声明两次** —— 是**加载期**语法错误，
   整个文件一行都不执行，页面看起来只是"空的"。
8. ⚠️ **CSS 注释漏一个 `*/` 会把后面那条规则整条吞掉**，不报错。加完大段注释数一下 `/*` 和 `*/`。
9. ⚠️ **`<use>` 只克隆被引用元素自己的子树** —— 样式写在包着 `<symbol>` 的 `<g>` 上**不会跟过去**。
10. ⚠️ **SVG 是标记不是文字** —— 塞 `icon()` 一律 `innerHTML`。
11. ⚠️ **网络要分两类走**：模型/包（hf-mirror、PyPI、api.github.com）**不带代理**；
    `github.com` 本身**要带代理**。`scripts/stt.py` 里已经把清代理写死。
12. ⚠️ **`ffmpeg` 的 `anullsrc` + `concat` 会挂死**（无限长的源），用 `say "[[slnc N]]"` 代替。
13. ⚠️ **Taro 那种把上一页留在 DOM 里的问题这里没有**（这是 Web，不是 Taro），
    但 `.taro_page` 相关的经验在 CEVTUO-Z 那边。
