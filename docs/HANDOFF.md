### ⚠️ 这一批最值钱的三条经验

**① 「改完验证全红」先怀疑改错了文件。**
写回清勾那处，我把改动落在了 `src/server.ts` 里一个**死掉的大字符串**（`const UI`，
全文只出现这一次、没有任何地方引用它）⇒ 浏览器跑的是 `src/ui/app.js` 那一份，
验证 5/11 全红。**白捡的负向对照**：那 5 条红得一模一样正是"把 bug 放回去"的样子。
⇒ 已经在 `const UI` 上面写了墓碑注释。

**② 同一天出两个日期块，根因是"写完立刻读"读不到。**
读者那两个块的 `created_time` **是同一秒** 06:18:00。我们的路径每条内容 spawn 一个进程，
find→create 之间**没有锁也没有记忆**；而 notion-clip 自己那条路是有缓存的。
⇒ 三层护栏：**文件锁**（flock）+ **复用它的持久缓存** + **建之前再确认一次**。
⭐ 缓存**不是**用来省扫描的（"今天有几个"只有扫描答得出，那个数要告诉读者）——
它是用来在**扫描还没看见刚建的块**时兜住的。这一条我先写错了断言，
是断言把设计缺陷逼出来的（`verify-append-dedup.py` ④ 那节）。

**③ 位置错了两周没人报，直到放了个不透明的东西上去。**
`.orbbg` 是 `inset:0`、光球按**整屏 50%** 居中，而语音屏下面那一摞占了小半屏
⇒ 本来就压住记录框。珍珠/水晶是圆形还羽化过，"压住一点"看着像"浮在上面"；
换成白底标本卡立刻变成"一张纸盖住输入区"。
⚠️ 顺手又量出一个**真正的逻辑错**：定心点写 `top/2 + 16`，一旦球高被压到等于空地高，
那 16px 平移就变成 **4px 压住**（`top/2+16 + (top-24)/2 = top+4`）。
**居中就是居中**，要留白得靠尺寸变量两边一起收。

### 第二批 —— 拖到货架 + 功能按来源放行
- **拖到货架**：根因两个 —— ① 语音那一屏 `#vlog > div` 没有 `draggable` 且 dragstart 只认 `.msg/.item`；② 更要命的是**"在 dragstart 里认元素不够，不可拖的元素根本起不了拖"**（`.card/.blk/.push` 从没被标过）。现在用 MutationObserver 兜底。
- **⭐ 常驻规矩：功能按来源放行**（读者原话「记得这件事情」）—— 只约束**读知识库那五个**（推荐/搜索/主题/词条/链接）；「融合」永远算有；**统计没读到时一律不拦**（否则是静默的过度惩罚）；**用 `.na` 类，绝不用 `aria-disabled`**（后者会让 Playwright 拒绝点击、屏幕阅读器跳过，"为什么不给点"就说不出口）。

**① 刷新键**（`#refreshBtn` / `window.__app.refresh()`）
⚠️⚠️ **它和「同步」必须是两个键**：刷新 = 按现在库里的东西重画这一屏（快、不联网、不会失败）；
同步 = 去各个来源拉新内容（几十秒、会失败、有配额、花钱）。
塞进一个按钮的后果是**用户点"刷新"触发了一次全量同步**，而那看起来只是"有点慢"。

**② 本机软件列表**（`src/apps.ts` / `/api/apps` / 「自我改进」那屏）
- 扫 `/Applications`、`~/Applications`、`/System/Applications`（含 Utilities），实测 **115 个**。
- ⚠️ **按名字去重**（不是按路径）：同一个 app 常常同时躺在 `/Applications` 和 `~/Applications`。

**③ 结构流自己的 log + 追问 + 后续处理**（`/api/flow/run` · `/api/flow/ask`）

- ⚠️⚠️ **会话 id 是 `flow:<runId>`，每次运行一条** —— 共用一条的话，

- ⚠️ ⚠️ **失败的那一步也要存**（不许只存成功的），否则"翻回去看"只剩半截。

- ⚠️ 结果**不再往右边那条对话里塞**了（读者说"也不是不可以"，但两处都铺的话，
  翻回去看时**不知道哪条是哪次跑的**）。底栏也只留一行摘要，明细在面板里。

## 4. 这一轮踩到的坑（别重踩）

1. ⚠️⚠️ **ImapFlow 的报错在 `e.responseText`，`e.message` 只有一句 `Command failed`。**
   只看 message ⇒ **「密码不对」被报成「连不上服务器」**，人被引去查网络。
   `e.authenticationFailed === true` 是它自己标的，比正则可靠。
2. ⚠️⚠️ **写 GBK 夹具必须 `printf … | iconv -f UTF-8 -t GBK | base64`，别手写字节。**
   我手写的解出「锅于辫伺单的存发件」，看着像解析器坏了，其实是**夹具坏了**。
3. ⚠️⚠️ **本机那份离线邮件库是加密的**：
   `~/Library/Containers/com.tencent.WeWorkMac/Data/Library/Application Support/WeMail/sqlite/<账号>/<企业>/MailContentDB.sqlite`
   没有 SQLite 头（首 16 字节是随机数），`load_encrypted*` 是空的。**别去逆向它。**
4. ⚠️ **松选择器会被新元素悄悄改掉语义**：`verify-flow2.mjs` 的 `$eval('.mbox.wide')` 匹配**第一个**宽弹窗，加了同步弹窗后 7 条断言一直在读**别的弹窗**（全假红）。已收紧成 `#flowhelp .mbox`。
5. ⚠️⚠️ **负向对照要打在"真的会坏的那一侧"（这已经是第五次了）**：测恢复条重叠时只测了「只收左栏」，而那个组合本来就不重叠 ⇒ 对照**红不了**，看起来像断言空跑。换成三种组合都测才真的会红。
6. ⚠️ **无头 Chromium 里 `Selection.toString()` 恒为空**（`document.hasFocus()` 为 false）。
   ⇒ "选中再拖"只能用**打桩**验处理器，断言里必须写明【打桩】。
7. ⚠️ **`aria-disabled="true"` 会让 Playwright 直接拒绝点击**（30s 超时），也让屏幕阅读器跳过。
   凡是"点得动、但要告诉你为什么点不了"的地方都用 `.na` 类。
8. ⚠️⚠️ **`$('#q')` 走的是 `document.querySelector` —— 元素还**没进 DOM** 就是 `null`**。
   我建了个游离的 `box`、在里面写了 `<input id="q">`，然后**先**接 `oninput`、**后** `appendChild`
   ⇒ 整个「词条」视图渲染中断成一屏空白（连手写块都没有），看起来像"这个功能没做"。
   ⇒ **先入 DOM，再查元素。**
9. ⚠️ **Playwright 的 `$eval` 回调在浏览器里跑，Node 那边的变量拿不到。**
   `(e) => e.textContent.includes(TAG)` 报 `TAG is not defined` —— 要**当参数传**：
   `$eval(sel, (e, t) => …, TAG)`。
10. ⚠️ **刷新之后视图会回到默认那一屏**。验证脚本里 `reload()` 之后不重开视图，
    `.mrow` 就是空的 ⇒ 假红（"刷新后不见了"和"我没在看那一屏"长得一模一样）。
11. ⚠️⚠️ **`[hidden]{display:none !important}` 会压过媒体查询**。
    窄屏那两颗抽屉把手**不能写 `hidden`** —— 写了的话它在窄屏也永远不出现，
