### C2. ⭐⭐ 修掉「点一个软件，宠物自己也不见了」

读者原话：「我点击中间软件 logo 之后**所有的一起消失了，连同中间的 pet，pet 不应该消失才对**」

**真因一行**：`app/pet/PetApp.swift` 的 `yieldActivation()` 里写的是 `NSApp.hide(nil)`
—— 那是**整个 App 的所有窗口**，而 pet 就是这个 App 的窗口。

⚠️⚠️ 而**正解在 `C4ememApp.swift` 里早就有**（`yieldPetActivation`，注释比这还长）：
`orderOut` → `NSApp.deactivate()` → 0.55s 后 `order(.above, relativeTo: 0)`。
**我在新 App 里重写时把它退回了最朴素那版。**
⇒ 教训：**抄的时候连注释一起抄** —— 注释就是防止下一次退回去的东西。

**验法（已固化）**：`bash scripts/verify-pet-keeps.sh`
- 用**真鼠标**（`scripts/mvtool.swift`）驱：悬停展开 → 点一个扇区
- 判据打在**原生窗口列表**上（`app/pet/wincheck.swift` 报 `kCGWindowIsOnscreen`），
  ⚠️ 不用截图 —— 宠物是**透明**小窗，截图上"它不见了"和"它压在深色上"长得一样
- ⚠️ 脚本**fail-closed**：桥里没有 `launch` 就报「**测试无效，不是通过**」（exit 2），
  不能把"点空了"读成"通过了"

**负向对照（实测，红过）**：

| | 点完那一下 |
|---|---|
| 把 `NSApp.hide(nil)` 放回去 | `launch Clash Party.app ok` ✓，宠物 `onscreen=0` —— **整个不见了**（症状逐字复现） |
| 修好之后 | `launch Google Chrome.app ok` ✓，宠物 `onscreen=1` —— **还在** |

## 三、关键决定（别推翻）

| 决定 | 理由 |
|---|---|
| **两个 App 共用同一个核心**（`~/.c4emem` 一个写入方） | 读者：「cevtuopet app 以及现在的 c4emem app **都是这个路子**」。各起一个 = 两个写入方抢同一个库 |
| **核心只能有一个**（先探 8770，活着就复用；没有我要的页面才起 8775） | 判据打在**真正要用的那个资源**上，不是"端口通不通" |
| **不自动写代码** | 这个项目早就否掉了：失败时是静默的。⇒ 走"模型填一张表 → 确定性地应用" |
| **抠图在浏览器里做** | 本机没有任何 PNG 编解码器（pngjs / sharp / jimp 都没有） |
| **只留最大的连通域** | 水印不是背景，会把包围盒撑到整张图 ⇒ "裁了等于没裁" |
| **两个 dmg 挂同一条发布** | `releases/latest/download/` 那条 302 是整条线共用的 |
| **形态名单只有一份**（`src/ui/petforms.js`） | 两份必然漂移，症状是"选了就空白"且不报错 |

## 五、几条这一轮新学到的（已写进 FACT）

1. **`open(f,'w').write(h + open(f).read())` 会把文件清空** —— Python 先求值 `open(f,'w')`
   （**那一刻文件已截断**），才去读 ⇒ 读到空的。**我又踩了一次**（把 `verify-petspin.mjs` 写成只剩 11 行）。
   ⇒ **先全读进变量，再写。**
2. **把"大改"和"小改"分开写落盘** —— 一个 `assert` 炸掉整段脚本，后面每一处改动**都没发生**。
3. **"拷现成的"会让两份核心悄悄不同步** —— 加了新路由只重建 pet，而它的核心是从已装的 c4emem 拷的
   ⇒ 新接口一律 404，**打包全绿、一个字都没报**。⇒ 把顺序变成脚本自己的事。
4. **假绿三连**（都发生在这一轮）：
   - 层数对 ≠ 有厚度（全叠在同一个 z 上）
   - `animation:none` 之后 computed 的 `animationName` **还是那个名字** ⇒ 要看 `getAnimations()`
   - 视频不吃 CSS 动画 ⇒ 只加类它还在播
5. **检查器报的假红要当检查器的 bug 修**：这一轮又修了两次（`bubble()` 里的 `**` 是**对的**；
   `card`/叠层形态**本来就没有 `<img>`**）。
