### A. ⭐⭐ 2D 图 → **真 3D**（读者：「不是仅仅加厚」）

**用的是现成的项目**，没有自己造轮子：

| 件 | 干什么 | 大小 | 出处 |
|---|---|---|---|
| **Depth Anything V2 (Small)** `model_q4f16.onnx` | 单张图 → 深度图 | 19MB | `onnx-community/depth-anything-v2-small`（Apache-2.0） |
| **transformers.js** + **onnxruntime-web (WASM)** | 在浏览器里跑那个模型 | 0.6MB + 14MB | npm |
| **three.js** | 位移网格 + 旋转 | 1.2MB | npm |

- **全离线**：没有任何一次联网请求，深度本机算（512² 约 **4.3 秒**）。
- 34MB 打进 `src/ui/vendor/`（**进 .gitignore**），由 `scripts/fetch-pet3d.sh` 拉。
  ⚠️ 模型走 **hf-mirror.com**（官方站 19MB 拉了 5 分钟没下来）。
  ⚠️ wasm 用**不带 asyncify/jsep 的那一份**（14.2MB 而不是 26.8MB，出图一模一样）。
- 唯一的实现：**`src/ui/pet3d.js`**（`estimateDepth` / `buildGeometry` / `mountPet3D`）。
- 验收：`bun scripts/verify-pet3d.mjs` —— **19 条**，走真路径
  （设置页上传 → 抠底 → 量深度 → 预览里在转 → 存 → 桌面上那只读它 → 主界面那只也读它）。

### B. ⭐⭐⭐ 「转不转还是没处理好」—— 真根因找到了

⚠️⚠️ **「银 / 铅 / 锌」在桌面上是 `mineral-*-mini.webp`，而那三张是动图 WebP**
（1~2.5MB，`ANIM` 块实测；无限循环）。
**CSS `animation:none` 对动图无效** —— 上一轮只想到 `<video>` 要单独 `pause()`，
漏了动图这一种（它长得就是一张"图"，最不容易想到）。

读者那台机器上的 pref 是 `{"form":"silver","spin":false}` —— 他碰到的正是这个：
把「不转」打开，**它照转不误**。

**修法**：这三种也走 3D 那条路（three 的贴图只上传一帧 ⇒ 天然停得住）。
深度图**预先算好**（每张 ~20KB，进 git），见 `scripts/make-pet-depths.mjs`。

**验收**：`bun scripts/verify-petspin-all.mjs` —— **21 条**，判据是**结果不是机制**：
同一形态在转/不转两种设置下各截两张图（隔 420ms）——
- 转 ⇒ 两张**必须不一样**；
- 不转 ⇒ 两张**必须逐字节相同**；
- 而且还要证明"那不是一张空图"（否则"定住"是假绿）。

### G. ⭐⭐⭐ 「点一个 App 图标，宠物闪一下」—— 已按读者要求**写死**

读者 2026-10-14：「我点击周围的 app 时候，中间这个 pet，**又开始闪一下**，

那 0.55 秒里**窗口真的不在屏幕上**（他的录屏第 46~55 帧整块是空的，只剩鼠标；
用 AVFoundation 抽帧看到的 —— 本机没有 ffmpeg，`/tmp/framedump.swift` 那个做法可用）。

**改法**（`app/pet/PetApp.swift`）：
- `yieldActivation()` **只留 `NSApp.deactivate()`** —— 让位要的是"取消激活"，不是"藏起来"。
  宠物窗本来就是 `hidesOnDeactivate = false` + `level = .floating` ⇒ 失活照样在屏幕上。

  下一个人（包括我自己）还会去调那个数字，而每个变体都会闪。
- 新增 `assertPetVisible(_:)`：**只放回、从不隐藏**，让位后 +0.1/+0.35/+0.8s 各确认一次。
  它单独成函数，是为了让"藏"在整个文件里**只剩一处**（菜单的 `togglePet`）
  —— `grep -n 'orderOut\|NSApp.hide' app/pet/PetApp.swift` 现在只出一行，可以数。
- `launch` 的兜底从"藏自己让路"换成**再激活一次目标 App**（不碰宠物）。

⚠️ 这一轮**按读者要求没有继续自测**（他说「你放弃自己录制和测试！」）——

### H. ⭐⭐⭐ 「一起造一只新的」四条入口 + 「选文件」的真凶

读者 2026-10-14：「我**给你随便一个 2D 图片**你能处理成 3D 然后做成 pet，
你为什么做不到！**这里粘贴复制，软件都处理不了**」
「支持选文件和贴链接**一个都不好用**！！！」

**「选文件」点了什么都不发生的真凶 —— 在 Swift 那边，不在网页里：**
> WKWebView 里 `<input type="file">` 被点击时，WebKit 会去问宿主的 UI 代理
> `WKUIDelegate.webView(_:runOpenPanelWith:initiatedByFrame:completionHandler:)`。
> **代理没实现 = 什么都不发生**（不报错、按钮不变灰、控制台一个字都没有）。
> 两个 App 原来都只挂了 `navigationDelegate`，**没有 `uiDelegate`**。

⚠️ 这一条特别值得记：它和"网页写错了""功能没做"长得**一模一样**。
⇒ 以后凡是 `<input type="file">` / `<select>` 在 WKWebView 里没反应，**先看这里**。

**改了什么：**
- `app/pet/PetApp.swift` · `app/C4ememApp.swift`：类声明加 `WKUIDelegate` +
  **两个 WebView 都挂 `uiDelegate = self`**（pet App 的**设置窗**那个最容易漏
  ——「一起造一只新的」就在那一页）+ `runOpenPanelWith` 实现。
- `src/ui/petsettings.html`：**四条入口，出口只有一个**（`feedFile` / `takeImage`）：
  ① 选文件 ② **⌘V 粘贴**（剪贴板是图片才拦，是文字就放行）③ **拖到窗口任何地方**
  ④ 链接（**直接给图片地址也认**；没写协议自动补 `https://`；当成网页失败会**再当成图试一次**）
  + 一个「读剪贴板」按钮（被权限拦时说清"直接按 ⌘V 就行"）。
- `keyOut()` 改成**四级降级、永不抛**：
  ① 图本来就有透明底 ⇒ 直接用它，不猜背景
  ② 四边泛洪抠得动 ⇒ 用它
  ③ 抠空 / 抠过头 ⇒ **原样不抠**照样能做 3D（界面如实显示"没抠底 · 原样"）
  ④ 连图都读不动 ⇒ 这才是真失败
  ⚠️ 原来只有第 ② 条，猜错就 `throw` ⇒ 白底 logo、已抠好的透明图、纯色图**一律"抠不了"**，
     而那正是"随便一个图"里最常见的三种。

**验收**：`/tmp/t4ways.mjs` 那套 **6/6**（选文件 / 拖 / 粘贴 / 图片网址 / 不带协议）
＋ 一张**不透明的白底 JPEG** 也走完了（抠出 9% 主体 → 79,202 面 3D）。

## 三、关键决定 / 踩到的坑（别推翻）

| 决定 | 理由 |
|---|---|
| **深度只算一次，存成一张灰度 PNG 跟着 Pet 走** | 算一次 4 秒 + 19MB 依赖；渲染那只 Pet 的窗口**不跑模型** |
| **内置那三种矿物的深度图预先算好、进 git** | 现算的话每开一次 Pet 都卡 4 秒 |
| **一条流水线管所有形态**（有深度图的一律 `3d`） | 两条渲染路必然漂移（本项目在名单上栽过） |
| **`if (a && b)` 不要包住要跑的步骤** | 跳过和通过必须长得不一样 |
| **ass 产物的文件名不带版本号** | `releases/latest/download/<名>` 那条 302 是 `no-cache` |

⚠️ **git**：本地仓库和远端 `main` 的**历史是无关的**（`no merge base`）。
`git pull --rebase` 会打架，**别做**。要推就把本地 `main` 推成一个**新分支**
（这一轮推的是 `pet3d-2026-10-14`）。⚠️ 远端那条
`0cee541 README：发行包说明` 是另一条历史上的，**别覆盖它**。

⚠️ **打包只重建一个 App ⇒ 另一个的 UI 快照是旧的**：
这一轮 `app/pet/build.sh` 只重建了 pet，`/Applications/cevtuo-c4emem.app` 还停在 0.1.27
（里面那份 `src/ui` 快照是旧的），**是 dmg 的版本号把它暴露出来的**。
⇒ 打 dmg 前先 `/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString'` 两个都看一眼。

⚠️ **在读者的真数据上动手之前先备份**：这一轮给那只银玫瑰补深度前
`cp ~/.c4emem/pets.json /tmp/pets.json.bak-…`。
