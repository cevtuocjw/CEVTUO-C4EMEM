结构流 = 一句话，只是每个成分你都能挑

先回答最容易卡住的那个问题：顺序有要求吗？

没有。块摆在哪、是第几个，都不影响它怎么跑 —— 决定关系的是连的那条线和 两端端口的类型，不是位置。一个块可以什么都不连，也可以接好几条线。

但有一条推荐的骨架，照着搭最省事：事件 → 来源 → 动作 → 去处。

事件→什么时候做（手动 / 到点了 / 切到某应用）
来源→拿什么做（我的笔记 / 网页 / 剪贴板 / 邮件）
动作→做什么（问 AI / 总结 / 翻译 / 归类）
去处结果去哪（写回 Notion / 放货架 / 存文件 / 念出来）

两头能省：没有事件 = 你手动点「运行」；没有去处 = 只出结果不落地。 中间那两块（来源、动作）才是这句话的主干。

端口颜色是什么意思

块两侧那些小圆点不是装饰，颜色就是类型 —— 绿的是「笔记」、蓝的是「文本」、 紫的是「事件」…… 画布上方那排图例就是它。

只有同一种类型才连得上。从「我的笔记」拉线到「问 AI」合法（前者吐笔记，后者收笔记）； 拉到「翻译」不合法（它只收文本）。拖线时能接的会亮、不能接的会暗，规则不用背。

主谓宾

主语 · 来源我的笔记 · 上网找 · 剪贴板 · 企业微信邮件 · Figma · 读文件
谓语 · 动作问 AI · 总结 · 查词翻译 · 归类 · 抽要点 · 判断
宾语 · 去处写回 Notion · 放货架 · 存文件 · 弹通知 · 打开 · 念出来 · 发手机
事件手动 · 到点了 · 切到某应用 · 复制了新东西 · 手机来通知
事件点火，它不在句子里 —— 但只有它能决定这句话什么时候被说出来。

线为什么有意义

因为每个接口有类型。把线从「我的笔记」拉到「问 AI」是合法的：前者吐笔记，后者收笔记。拉到「翻译」就不合法 —— 它只收文本。

如果每个口什么都收，线就只是装饰：画得好看，什么也保证不了。所以限制只加在类型上，不加在内容上 —— 每块里爱写什么写什么。

拖线的时候，能接的会亮、不能接的会暗，规则不用背。

三种线

数据流（实线）把 A 的输出当 B 的输入 —— 最常用，直接拖
顺序（虚线）Shift + 拖。A 跑完再跑 B，不传数据，只表示先后
条件（点线）Alt + 拖。A 的判断为真，才跑 B

不拖也能全做完

⇧ + 方向键朝那个方向新建一块并连上 —— 这就是「分叉」
⌥ + 方向键只连一条顺序线到最近那块，不新建
Tab / ⇧Tab在块之间移动
Enter / / / Delete编辑 / 换类型 / 删掉
⌘ + Enter跑

只有「宾语」那一步会动到外面

写回 Notion、发通知、打开东西、存文件 —— 这些真的会改变外面的世界。这类块标着「会动到外面」。

货架 = 你先把它放在这儿，待会儿再用

能往上放的，比你以为的多

拖记录里的任一条 · 对话里你发的或它答的 · 语音那一屏的每一句 · 多选几段一起拖
选中再拖在哪儿都行 —— 选中一段文字直接拖过来，不用先复制（画布上的块、知识库的卡片都算）
复制在外面按 ⌘C，回这儿按 ⌘V（焦点别在输入框里）；或者点货架上那颗「＋ 剪贴板」
选中 + 点货架万能的一条：选中任何一段文字，然后点一下货架 —— 不看它是什么元素、在哪个页面
图片 / 文件从访达或网页直接拖进来，或者复制图片后粘贴 —— 图上会带缩略图
网页链接拖一个链接进来，记的是地址和标题

放进去之后

送去回答把架子上的东西一起丢给 AI，让它拿这些当材料答
加进结构流变成结构流里的块，接着往下接动作
再拖出去架子上的每一项自己也能拖走

为什么要有这个东西

因为你收集东西的时候还不知道要拿它干什么。先丢进来，等想法成形了再决定 —— 中间不用去开一个新的笔记、也不用把这段话先粘到别处。

它只在本机

货架存在浏览器本地（localStorage），不上传、不同步。清掉浏览器数据它就没了。
